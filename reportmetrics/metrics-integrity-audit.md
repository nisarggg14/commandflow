# CommandFlow metrics integrity audit

Status: **current fixture-only benchmark measured and validated; Gemini and production/MCP metrics not measured**.

## Scope and safety

The audit inspected the benchmark writer, raw CSV, summary, methodology, paper-ready and black-book reports, and historical evidence. No application security control, dataset gold label, IEEE paper, database, credential, approval, MFA challenge, real MCP tool, external API, or Gemini request was used.

The historical `metrics-report/benchmark-harness.mjs` remains preserved but is not a safe current generator: it imports the MCP server and executes a tool. The current run used `scripts/run-commandflow-fixture-benchmark.mjs`, which contains only deterministic local mocks and explicitly performs no MCP, database, or external calls.

## Findings and corrections

1. The CSV writer now uses RFC CSV quoting, including doubled embedded quotes, so JSON argument fields are valid CSV fields.
2. The unsafe historical raw CSV is preserved as `benchmark-results-canonical-historical.csv`. The current `benchmark-results.csv` was generated by the isolated fixture-only harness, not by the unsafe MCP harness.
3. The current file parses with exactly 12 columns per record: 40,000 latency rows and 8 fixture rows. Each operation has 10,000 latency samples and all fixture expected/observed outcomes match.
4. Percentiles use nearest rank (`ceil(p*n)-1` zero-based index), standard deviation is population SD, throughput is samples divided by measured batch wall-clock seconds, and no outlier is removed or winsorized.
5. The summary and current reports now use the fresh fixture-only values. Historical live-MCP-labelled values remain separate and are not combined with them.
