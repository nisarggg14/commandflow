# CommandFlow metrics report

Status: current fixture-only metrics are measured and validated; model and production/MCP metrics are not measured.

## Current evidence source

The authoritative current benchmark evidence is `benchmark-results.csv`, generated by `scripts/run-commandflow-fixture-benchmark.mjs` and validated by `scripts/validate-commandflow-benchmark.mjs`. It contains deterministic local mocks only: no MCP server import, tool execution, database access, external request, approval/MFA operation, or Gemini call.

The historical `metrics-report/benchmark-harness.mjs` and historical raw records are retained separately because that harness imports the MCP server and executes a tool. They are not the current generator.

## Repository facts

The source audit identified 33 registered tools, 21 API routes, 12 Prisma models, seven migrations, and seven tool categories. These are source inventory facts, not performance or security guarantees. No application code or security control was changed for this report.

## Safety and model status

The eight deterministic fixtures matched their expected outcomes. This finite fixture result is not a general security rate. Role authorization, high-risk approval/MFA, database/TLS behavior, live external clients, and authenticated end-to-end testing were not executed.

Live Gemini tool-selection accuracy, exact arguments, precision/recall/F1, latency, robustness, throughput, cost, and execution success remain **NOT MEASURED**. The 63 labelled cases are evaluation inputs, not successful model scenarios. The paper's historical 60/60 automated-test, 63/63 scenario, and later 68/68 project-test figures remain distinct and are not replaced here.

## Historical evidence and limitations

`metrics-integrity-audit.md` explains the old conflicting medians/p95 values and preserves the prior raw/report artifacts. The configured application test-runner, typecheck, lint, build, database/TLS checks, and live QA have their historical statuses in the preserved reports; this current fixture report does not convert those records into new results.
